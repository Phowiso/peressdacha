Игра «Угадай число» наоборот

Требуется установленный Clojure.

1. Открой терминал в папке с game.clj.
2. Запустить REPL командой clojure.
3. Выполнить:
   (load-file "game.clj")
   (start 1 100)
   (guess-my-number)

Загадать целое число в указанном диапазоне, включая его границы.
(smaller) — загаданное число меньше предложенного.
(bigger) — загаданное число больше предложенного.
Когда программа назовёт твоё число, игра завершена.
Для новой игры снова вызови (start 1 100) или задай другие границы.

Пример для числа 23:
(guess-my-number) ; 50
(smaller)         ; 25
(smaller)         ; 12
(bigger)          ; 18
(bigger)          ; 21
(bigger)          ; 23
