Плоттер в функциональном стиле
Запуск:
  Установите Node.js версии 22.18 или новее.
  В папке с файлом выполните:
    node plotter.ts

Изменения:
1. Состояние описано через Readonly; команды создают новые объекты.
2. Команды не печатают сообщения, а возвращают состояние и журнал.
3. sequence объединяет команды с помощью reduce, без переназначения состояния.
4. Повторение сторон фигур задано через Array.from и композицию команд.
5. Вывод в консоль выполняется отдельно, после вычисления результата.
6. Общая функция drawPolygon используется для треугольника и квадрата.

Сохранены исходные координаты, округление, цвета, повороты и порядок сообщений.
Текст названия чёрного цвета оставлен как в исходнике, чтобы вывод совпадал.
